## Safety and backups

Patching modifies files inside the Antigravity installation. The patchers create `.ba-backup` files where applicable so changes can be reverted. Close Antigravity before applying a patch whenever possible.

The link-approval fix disables an external-link confirmation step. It is optional and should only be enabled when the user understands the trade-off.
